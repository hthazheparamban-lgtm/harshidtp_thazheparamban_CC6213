# Conduit Backend API

A scalable RESTful backend API for a social blogging platform built with Node.js, Express.js, MongoDB, and Redis.

## Features

- JWT Authentication
- Article CRUD
- Comment System
- User Following
- Redis Caching
- Redis Pub/Sub
- Layered Architecture

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Redis
- JWT
